# AI Digital Fraud Detection

An AI/ML-based project for detecting potentially fraudulent digital transactions using machine learning.

## 📌 Project Overview

Digital payment fraud is a growing problem. This project analyzes transaction data and uses a machine learning model to identify whether a transaction is potentially fraudulent.

## 🚀 Features

- Fraud transaction detection
- Machine learning-based prediction
- Transaction data stored in CSV format
- Database connectivity
- Trained ML model saved as `.pkl`
- Simple Python-based implementation

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- SQLite / Database
- Git & GitHub
